# AI_CONTEXT.md — System Capabilities & Tech Stack Context

## Codebase Identity
FG Lift Pvt. Ltd. is an enterprise B2B elevator and vertical transport platform.

## Key Architectural Layers
1. **Next.js App Router**: Route segments under `src/app/`.
2. **Design System & Tokens**: Core variables in `src/design-system/` and `src/app/globals.css`.
3. **SEO Engine**: Dynamic JSON-LD, OpenGraph, Twitter, and canonical URL generators in `src/seo/`.
4. **Performance Engine**: Multi-tier caching, Web Vitals, and Three.js memory disposal in `src/performance/`.
5. **Security Architecture**: Rate limiting, XSS sanitization, HTTP security headers, and API pipeline validator in `src/security/`.
6. **Modular Admin Console**: CRM, products, gallery, blog, newsletter, logs, command palette, and notification center in `src/app/admin/` and `src/components/admin/`.
