# Admin Console Guide — FG Lift Pvt. Ltd.

## Overview
The Admin console provides CRM, CMS, and platform management tools for FG Lift staff.

## Key Features
- **Dashboard**: Metric stat cards, recent leads table, quick actions.
- **CRM Pipeline**: Kanban board and filterable table views for inquiry lifecycle tracking.
- **Content CMS**: Product catalog, landmark gallery, and editorial blog post management.
- **Marketing & Email**: Newsletter subscriber roster, CSV exports, and email template customization.
- **System Management**: Role-based team member provisioning and immutable audit log feed.
- **Productivity Tools**: Global `Ctrl + K` Command Palette and Notification Center drawer.
