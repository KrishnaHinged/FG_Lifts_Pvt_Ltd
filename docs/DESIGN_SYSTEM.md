# Design System Documentation — FG Lift Pvt. Ltd.

## Design Philosophy
The design system combines industrial precision with warm luxury aesthetics. Inter is the universal typeface, paired with subtle borders (`#E8E2DA`), deep blue primary accents (`#0E4FB3`), and rich neutral surfaces (`#111111`, `#EDE8E2`).

## Design Tokens (`src/design-system/tokens/`)
- `colors.js`: Brand palette, semantic status colors, and neutral background tokens.
- `typography.js`: Inter font family hierarchy, line heights, and font weights.
- `radius.js`: Standardized border radii.
- `transitions.js`: Framer Motion transition curves.
