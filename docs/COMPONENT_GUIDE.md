# Component Guide — FG Lift Pvt. Ltd.

## Component Categories

### 1. Typography (`src/components/typography/`)
- `<HeroTitle>`: Large header title for hero banners.
- `<Heading>`: Main section titles.
- `<Paragraph>`: Standard editorial copy.
- `<Label>`: Form and input labels.

### 2. Layouts (`src/components/layouts/`)
- `<Section>`: Page section with configurable dark/light backgrounds.
- `<Container>`: Max-width content boundary.
- `<Grid>`: Responsive grid layout.

### 3. UI Primitives (`src/components/ui/`)
- `<PrimaryButton>`, `<IconButton>`, `<LinkButton>`: Standardized button variants.
- `<Badge>`: Status and category indicators.
- `<SearchBar>`: Search input with icon.
- `<Table>`: Reusable data table container.
