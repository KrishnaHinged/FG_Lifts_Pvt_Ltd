# COPILOT_GUIDE.md — GitHub Copilot Code Completion Rules

- Generate standard JavaScript (.js) and React JSX (.jsx) code.
- Avoid introducing any TypeScript syntax (interfaces, types, generics, : string, etc.).
- Prefer functional components with hooks over class components.
- Standardize colors using CSS custom properties (`--font-inter`, `--text-body`, `#0E4FB3`, `#111111`, `#E8E2DA`).
